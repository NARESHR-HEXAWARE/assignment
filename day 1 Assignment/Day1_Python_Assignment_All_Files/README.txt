DAY 1 — PROBLEM SOLVING TECHNIQUES AND DATA STRUCTURES — I

These are Python assignment solutions for all three sets in the uploaded Day 1 brief.
Each set contains a standalone Python script and a captured console-output file.
Set 1 also contains generated 50,000-row orders.csv.

HOW TO RUN
  python set1_retail_orders.py
  python set2_banking_review.py
  python set3_hospital_appointments.py

All scripts use only the Python standard library (Python 3.10 or later recommended).
Measurements in the output files are from one run and will differ on your machine.
